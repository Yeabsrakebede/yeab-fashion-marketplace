# YEAB Fashion Marketplace — free static prototype

## What's included
- Responsive homepage for mobile and desktop
- Sample clothing catalog with search and category filters
- Designer invitation section and application-message download
- Instructions for publishing with GitHub Pages

## Important limitations
This is a static front-end prototype. Product cards are sample designs, not real inventory. It does not yet include secure accounts, real designer uploads, a database, customer orders, admin permissions, or commission/payment processing. Do not collect money or promise these features work until a backend is built and tested.

## Publish on GitHub Pages (phone-friendly steps)
1. Sign in at https://github.com/
2. Create a new public repository named `yeab-fashion-marketplace`.
3. Upload `index.html`, `styles.css`, and `script.js` from this folder to the repository's root.
4. Open the repository's **Settings** → **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub Pages to provide the public URL. It may take a few minutes.
8. Open the URL and test it on your phone.

GitHub Pages is free for public repositories, but it only hosts static files. A secure marketplace backend needs a separate service and may have usage limits or costs.
